# Noma Frontend

The savings app for everyone — save alone, with family and friends, or as a community.

## Design & System Principles
- **No cards, no dashboards**: Open page layouts, clear sections, meaningful lists and dividers.
- **Typography**: Inter 4.1 from Rasmus Andersson's CDN (`rsms.me`).
- **Palette**: Primary `#1F4591`, Action blue `#2B6AD0`, Soft emphasis `#68A4F1`, Deep ink `#061E47`, Page `#FEFEFE`, Alert `#FF6347`, Success `#3CB371`.
- **Public & Signed-in Separation**: Public landing page has at most 4 navigation items; app navigation is distinct and dedicated.
- **Explicit Permissions & Trust**: Visibility, contribution, and payout rights are granular and explicit.

## Stack
- Next.js 16 (App Router, Turbopack, Partial Prerendering)
- React 19, TypeScript
- Tailwind CSS 4

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
